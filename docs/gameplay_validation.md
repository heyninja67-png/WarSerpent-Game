# Gameplay validation — version 1.1

Engine: **Godot 4.6.3 stable**. These checks ran on the Linux development server. They do not establish Android device frame rate or hardware touch latency.

## Automated model and arena checks

```sh
godot --headless --path . --script tests/test_gameplay.gd
```

**46 checks passed; zero failures** in the final run. Coverage includes:

- A new player starts at 36 mass with ten connected segments; growth increases length and score.
- Constant-speed movement, time independence at 30/60 steps per second, distance-sampled curves, and long-snake circular-history wraparound.
- Boost changes actual speed, consumes mass, and respects the 12-mass floor.
- All eight catalog cooldowns/durations match executable model values.
- Electric Overdrive speeds up; Flame Burst slows nearby opponents; Frozen Trail leaves real slowing areas; Cyber Shield consumes one eligible collision; Phantom Shift temporarily avoids collision and slow; Solar Magnet collects at extended range; Samurai Dash changes speed briefly; Toxic Cloud slows enemies in its area.
- Spatial hashing across adjacent and negative-coordinate cells, real food deactivation/collection, head/body elimination, killer credit, defeat transition, and actual result statistics.
- Three independent touch identities for joystick, boost, and skill; releasing the joystick preserves a held boost. Android mouse emulation is ignored by gameplay so a touch cannot toggle pause twice.
- Remote controls use the same movement/skill implementation; network clients can turn off local authoritative simulation.

The functional UI test additionally dispatches real input events through Godot. Its latest integration run passed **119 checks**, including multi-touch pause/resume, the loading/menu/play/death/results/restart flow, eight skins, and persistence. See the retained test logs and screenshots generated by the integration suite. Online room checks are documented separately in [ONLINE.md](ONLINE.md).
